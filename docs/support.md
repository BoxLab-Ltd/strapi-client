## Free ways to help

These matter as much as money, and several of them matter more:

- **Star the repository** — [github.com/BoxLab-Ltd/strapi-typed-client](https://github.com/BoxLab-Ltd/strapi-typed-client). It's the main way other developers find the project.
- **Report bugs with a reproducible schema.** A content type that triggers the wrong generated type is worth more than a paragraph describing it.
- **Report what's missing.** Gaps in populate inference, filters, or the generated client are hard to find from the outside — issues are where they surface.
- **Write about your setup.** Blog posts and tutorials bring in the people who'd never search npm for this.
- **Answer questions** in [issues](https://github.com/BoxLab-Ltd/strapi-typed-client/issues) if you've solved something someone else is stuck on.

## Security

Found a vulnerability? Don't open a public issue — see the [security policy](https://github.com/BoxLab-Ltd/strapi-typed-client/blob/main/SECURITY.md) for how to report it privately.
